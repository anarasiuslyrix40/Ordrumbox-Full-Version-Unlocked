## Main Features
<a id="main-features"></a>

### Core Functionality
- **Rhythmic Pattern Creation** — Users can create songs by composing rhythmic patterns, defining the number of 'hits' for each pattern, allowing for intricate beat designs.
- **Multi-Track Support** — Utilize an unlimited number of sounds (tracks) for each pattern, providing extensive options for layering and complexity in compositions.
- **Sound Adjustment** — Modify pitch, panorama, volume, and other settings for each sound, enabling precise control over the final output.
- **Polyrhythmic Capability** — Add loop points to each sound, facilitating complex rhythm structures that challenge traditional beat-making boundaries.
- **Automatic Composer** — Use the arpeggio functions to generate new rhythm patterns, variations, and melodic scales effortlessly.

### Advanced Capabilities
- **Sound Library Organization** — The software automatically organizes the sound library based on its nature, streamlining the workflow for users.
- **MIDI File Support** — Import and export MIDI files, allowing seamless integration with other audio production tools and DAWs.
- **Custom Sound Creation** — Users can modify their sound collections and store results as new kits, enhancing the versatility of their projects.
- **Virtual Synthesizer** — Access a virtual synthesizer to create new and exclusive sounds, expanding the creative possibilities within Ordrumbox.
